# vic10.us

Source for [vic10.us](https://vic10.us): projects, demos, 3D prints and a retro terminal with a few things hidden in it.

Built with [Astro](https://astro.build). Deployed on Cloudflare Pages.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

Content lives in `src/data/site.ts`. The shell and easter eggs live in `src/scripts/page.ts` (no peeking).
